# Web Crawler

Десктопний застосунок для веб-сканування сторінок із графічним інтерфейсом (JavaFX), семантичною очисткою HTML, збереженням структурованих даних та веденням статистики у локальній базі даних SQLite.

---

## 📌 Можливості

- Сканування веб-сторінок, починаючи з вказаного стартового URL.
- Перехід за внутрішніми посиланнями (BFS).
- Обмеження максимальної кількості сторінок для сканування.
- Пошук входжень заданого ключового терміну.
- Очищення HTML від:
  - `<script>`, `<style>`, `<meta>` та інших службових тегів;
  - рекламних блоків;
  - структурних елементів: `header`, `footer`, `nav`, `aside`;
  - технічних елементів, що не несуть семантичного змісту.
- Збереження очищених HTML-сторінок у директорію: `data/pages`.
- Запис статистики в SQLite-базу (`data/crawler.db`):
  - URL сторінки;
  - заголовок сторінки;
  - статус обробки (OK / ERR);
  - кількість входжень ключового терміну (hits);
  - шлях до локального HTML-файлу;
  - дата й час сканування.
- Графічний інтерфейс (JavaFX).

## 🧱 Архітектура

Проєкт побудований на основі **багатошарової архітектури** з використанням **подієвої моделі**.

### Основні модулі

```text
src/main/java/com/crawler/
│
├── core/      # Ініціалізація застосунку, запуск JavaFX
├── ui/        # JavaFX інтерфейс, контролери, віджети
├── crawler/   # Логіка сканування, обхід посилань, BFS
├── utils/     # Очищення HTML, хелпери, валідатори
├── storage/   # Робота з SQLite, DAO-класи
└── models/    # Моделі даних (Page, CrawlResult тощо)
```

---

## 🧩 Використані шаблони проєктування

- **Observer (Listener)** – UI підписується на події краулера та оновлює прогрес, таблицю результатів і статуси в реальному часі.
- **DAO (Data Access Object)** – виділений шар для роботи з базою даних, ізоляція SQL-запитів від бізнес-логіки.
- **SRP (Single Responsibility Principle)** – кожен клас відповідає за одну конкретну задачу (сканування, очищення, збереження тощо).
- **Layered Architecture** – чітке розділення на шари:
  - UI (JavaFX),
  - Business Logic (crawler, utils),
  - Data Access (storage, DAO).
- **Strategy-подібна структура** – модульна побудова компонентів:
  - `HtmlCleaner`,
  - `PageFetcher`,
  - `LinkExtractor`,
  що дозволяє легко замінювати/розширювати окремі частини.

## 🗄 Структура бази даних

Використовується SQLite-база даних: `data/crawler.db`.

### Таблиця `pages`

| Поле       | Тип     | Опис                        |
|------------|---------|-----------------------------|
| id         | INTEGER | первинний ключ (AUTO_INCREMENT) |
| url        | TEXT    | адреса сторінки             |
| title      | TEXT    | значення `<title>`          |
| status     | TEXT    | статус сканування: OK / ERR |
| hits       | INTEGER | кількість входжень терміну  |
| file_path  | TEXT    | шлях до збереженого HTML-файлу |
| crawled_at | TEXT    | дата й час сканування       |

## 🖼 Інтерфейс

Графічний інтерфейс побудований на JavaFX та забезпечує повноцінну роботу без консолі.

Основні елементи UI:

- поле введення стартового **URL**;
- поле введення **ключового терміну** для пошуку;
- поле **Max pages** для обмеження кількості сторінок;
- кнопка **Start** для запуску сканування;
- **progress bar** для відображення прогресу;
- таблиця зі списком оброблених сторінок та їхнім статусом:
  - URL,
  - заголовок,
  - статус,
  - кількість входжень терміну,
  - шлях до файлу.

## 🚀 Запуск проєкту

### Вимоги

- **Java 17+**
- **Maven 3+**
- Доступ до Інтернету для завантаження залежностей

### Команди запуску

```bash
mvn clean javafx:run
```

Після успішного складання відкриється JavaFX-вікно програми.
